# Portfolio Optimization using Markowitz

## Objetivo

Construir un portafolio óptimo utilizando la Teoría Moderna de Portafolios de Harry Markowitz y comparar su desempeño frente al índice S&P 500.

## Tecnologías

- Python
- Pandas
- NumPy
- SciPy
- Matplotlib
- Plotly
- yfinance
- Streamlit

## Estructura

- data/: Datos del proyecto.
- notebooks/: Análisis y desarrollo.
- src/: Funciones reutilizables.
- reports/: Figuras y reporte final.
- app/: Dashboard en Streamlit.
